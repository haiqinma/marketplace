# 技能名称 / Skill Name

## 中文

### 用途

说明这个 Skill 解决什么问题、适合什么场景。

### 能力

- 列出主要能力。
- 说明必要的工具或配置。

### 边界

说明权限、安全、数据和不支持场景。

## English

### Purpose

Explain the problem this Skill solves and when it should be used.

### Capabilities

- List the primary capabilities.
- Describe required tools or configuration.

### Boundaries

Describe permission, safety, data, and unsupported-use boundaries.
